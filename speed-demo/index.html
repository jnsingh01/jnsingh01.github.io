Speed demo: one product page, before and after

The same product page built twice. The first version has the six problems I most often find slowing a Shopify store down. The second has them fixed. Nothing else changes: same layout, same copy, same photos, and the same amount of third-party script work.

This is a mock page for a made-up desk brand, not a client's store. The "app" script is a stand-in that does 350 ms of work, the way a typical review or upsell app does when it starts up.

Open the before page Open the after page

What was wrong, and what I changed

  1. Fonts held up the page. Two font families in fifteen weights, with no preconnect and no font-display. Now only the three weights actually used load, text shows straight away in a fallback font, and the connection to the font server opens early.
  2. jQuery and a carousel plugin loaded in the head. Four files had to download and run before anything could appear. The carousel is now CSS scroll-snap: no library at all.
  3. An app script blocked the first paint. Its 350 ms of start-up work ran before the page could show. The same work still runs, but after the page has loaded, in 8 ms slices while the browser is idle, so it never gets in the way of the first paint or a tap.
  4. The main product photo was a 2.3 MB, 2400 px JPEG, and couldn't appear until the carousel started. It is now AVIF or WebP at 600, 900 or 1200 px (whichever the screen needs), preloaded, marked high priority, with its width and height set.
  5. Photos further down loaded straight away at full size. They now load only as you scroll near them, sized for their slot.
  6. A reviews widget pushed the page down after it loaded. That is layout shift, the reason people tap the wrong button. The reviews now render with the page, so nothing moves.

Doing this on a real store

On a live Shopify theme the same six fixes are Liquid and asset changes: image_url with image_tag widths, preload: true on the product image, app embeds deferred or removed, and space reserved for anything an app injects.
